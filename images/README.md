# 图标资源说明

## 本目录用于存放小程序所需的图标文件

### 需要的图标文件列表：

#### TabBar 图标（58x58px）：
- home.png / home-active.png          - 首页图标
- category.png / category-active.png  - 分类图标
- plan.png / plan-active.png          - 食谱图标
- tools.png / tools-active.png        - 工具图标
- profile.png / profile-active.png    - 我的图标

#### 其他图标：
- default-avatar.png                  - 默认用户头像（200x200px）

### 图标设计建议：
1. 图标风格统一，建议使用线性图标
2. 选中状态使用主题色 #ff6b35
3. 未选中状态使用灰色 #999
4. 保持简洁明了，避免过于复杂的细节

### 临时方案：
由于本项目中已使用 icon 组件替代大部分图标，且图片资源均来自 picsum.photos 服务，因此这些图标文件不是必需的。小程序可以正常运行。
